# 手绘量房图采集与识别规则

版本：1.0
适用范围：单房间量房草图，包括卫生间、厨房、卧室等正交或近似正交空间。
目标：让系统从照片中恢复有证据支撑的毫米级平面图；信息不足时只要求用户确认最少的歧义项，不静默补造尺寸。

## 1. 基本原则

1. 墙体图形表示空间拓扑，标注数字决定最终毫米坐标；墙体不要求按比例绘制。点位是例外，必须按其在房间中的相对位置落在草图内。
2. 所有平面尺寸默认表示房间内侧完成面净尺寸；标题区未勾选时也按完成面处理。只有测量毛坯面时才需要勾选“毛坯面”。
3. 单张纸只画一个房间；复杂套间拆成多张，并用相同门洞编号关联。
4. 不依赖住宅常识补齐未画出的墙、门窗、设备或尺寸。
5. 识别结果必须能够回到原图中的文字或线条证据；没有证据的关键字段不能自动确认。

## 2. 推荐纸张与用笔

- 使用 A4 或 A3 白纸，推荐打印带四角定位标记和浅灰方格的量房模板。
- 全图只需使用一支黑色或深蓝色笔，不要求准备多种颜色。
- 推荐 0.5 mm 左右笔宽。铅笔、浅色圆珠笔和荧光笔只作为兼容输入，不作为推荐方式。
- 依靠位置和符号区分内容：墙体画连续实线；尺寸放在轮廓外侧并带尺寸线；门窗使用 `D/W` 编号；点位直接画标准符号并写简称；高度使用明确文字标签。
- 文字、尺寸线和墙线不得重叠。

## 3. 墙体与轮廓

1. 沿房间内侧完成面画一条拓扑连续的闭合轮廓；首尾测量值存在少量误差不等于轮廓识别错误。
2. 墙角、墙垛、柱、包管、门框短回折都必须画出真实转折，不得用外接矩形代替。
3. 默认墙段水平或竖直；斜墙必须标注角度，或给出两个端点相对同一基准的 X/Y 尺寸。
4. 墙线与尺寸线之间至少留出一个数字高度的间距。
5. 门洞处允许墙线中断，但门扇圆弧不得作为房间边界。

## 4. 尺寸标注

1. 单位统一为毫米，只写整数，不在每个数字后重复写 `mm`。
2. 数字横向正写；竖墙尺寸也优先横向书写，避免旋转数字。
3. 数字必须位于对应尺寸线中点附近，不得跨越墙线、符号或其他数字。
4. X、Y 两个方向均应提供一组连续分段尺寸链，并至少提供一个对应总尺寸。
5. 总尺寸与分段尺寸链是校验关系，不得用总尺寸替代重要转折处的分段尺寸。
6. 墙线在纸上画得长或短与实际毫米长度无关；程序只用线条判断连接、转折和凹凸，实际长度完全由标注数字与闭合方程决定。
7. 同一尺寸不要在多个无关位置重复书写；确需复核时标记 `复核`。
8. 写错后用一条线划掉，在旁边空白处完整重写；禁止涂黑、描粗或覆盖原数字。
9. 同一方向的尺寸链闭合采用有上限的现场误差容差：至少 `20 mm`，按该方向尺寸链的 `1.5%` 放宽，最多 `100 mm`。容差内系统自动选择一段普通墙体吸收误差；原始实测值永久保留，建模长度标记为 `derived`，并记录正负闭合调整量。超过容差才要求复核。

## 5. 门窗与固定结构

- 当前模板固定保留一门两窗：`D1`、`W1`、`W2`。没有对应洞口时该行留空。
- 平面图画出洞口位置并标编号；对象表统一填写 `CG`、`CK`、`CH`。
- `CG` 表示洞口下沿距完成地面的高度，`CK` 表示洞口内侧净宽，`CH` 表示洞口内侧净高；门的 `CG` 通常实测为 `0`，不能由程序默认补写。
- 洞口至少需要：所在墙、图中位置、`CG`、`CK`、`CH`。任一项缺失时结果保持待确认。
- 柱、包管等侵入空间的结构必须画出占地轮廓，并至少标宽、深两个尺寸。

| --- | ---: | ---: | ---: |
| D1 | 0 | 800 | 2055 |
| W1 | 900 | 1200 | 900 |
| W2 |  |  |  |

## 6. 点位与高度

1. 点位不填写 X/Y 表，直接画在平面草图的实际相对位置；地漏用 `⊗`、排水用 `○`、给水用 `△`、电点用 `□`，并在符号旁写简称。
2. 系统识别符号中心，并按照片墙体轮廓到已闭合毫米边界的相对比例计算位置；该坐标标记为 `derived`，保留原图证据框，可在二维图中拖动修正。
3. 图形不按比例或点位贴近墙线、文字遮挡符号时，相对坐标只能进入待确认，不能伪装成实测坐标。
4. 高度表填写室内净高；整屋吊顶高度允许直接写在房间轮廓中央，例如 `吊顶 2100`，系统自动将其应用到整个房间，但绝不能用吊顶高度替代净高。
5. 局部吊顶、梁底或跌级高度必须写在对应区域内或用引线圈定；高度表不要求填写“对应区域”备注。
6. 图中未带数值的长文字只作为备注，不能替代尺寸。

## 7. 拍照要求

1. 完整拍到纸张四边和四角定位标记，不裁掉尺寸或对象表。
2. 镜头尽量垂直纸面；避免折痕、阴影、反光和手指遮挡。
3. 原图长边不少于 2000 像素，数字笔画放大后应连续可辨。
4. 一次拍摄不清楚时重新拍摄，不用聊天软件压缩图替换原图。

## 8. 旧草图兼容规则

系统接受不符合上述颜色和版式的旧草图，但按以下方式降级处理：

- 视觉模型和 OCR 只产生候选证据，不直接生成已确认尺寸。
- 几何求解器在墙体拓扑闭合、尺寸链精确闭合或误差处于上述比例容差内、且关键字段有直接证据时自动通过。
- 不满足唯一解条件时显示 1 至 3 个最关键问题，例如“右墙是 1840 还是 184？”或“800 是否为门宽？”。
- 用户确认一个数字后重新求解全图，不要求逐点编辑坐标。

## 9. 自动通过条件

只有同时满足下列条件，识别状态才能成为“可确认”：

1. 房间边界闭合、不自交，所有连续墙段端点一致。
2. 每个关键墙长、总尺寸、洞口 `CG/CK/CH` 和净高均有可定位到原图的证据。
3. 水平与竖直尺寸链分别闭合；实测冲突处于上述比例容差内时允许自动生成派生闭合值，但必须同时保存原始实测值、闭合调整量和建模采用值。
4. 开口完全落在所属墙段内；结构和点位位于房间边界内或明确标记为墙内对象。
5. OCR 候选、视觉绑定和几何约束没有未解决的高风险冲突。
6. 系统没有使用默认值替代缺失的关键量房数据。

任何一项不满足都必须进入“需要确认”，并在原图上标出对应证据区域。

## 10. 校正交互要求

- 点击原图数字即可修改数值或切换 OCR 候选。
- 点击数字后再点击墙段，可以重新绑定尺寸归属。
- 点位符号识别后直接显示在二维图中；位置不准时拖动符号即可修正相对坐标。
- 修改一个尺寸后自动重算相关墙体、开口和闭合检查。
- 拖动角点时默认吸附水平/竖直方向，并实时显示是否闭合。
- 只突出显示冲突和低置信度项；已验证证据保持可追溯但不干扰审图。
- 所有修改支持撤销、重做和保存，确认后仍保留原图证据与修订记录。

## 11. 当前样例的验收重点

对 `test0.jpg`（当前模板实拍样例），Git 只保留 `evidence/samples/real/agen-24-point-marker-test/manifest.json` 中的脱敏来源、哈希、尺寸和用途；原图由获授权的外部测试存储保管，并通过命令行参数传入。新增测试图使用前必须按图片内容 SHA-256 去重，不得把原图或派生截图提交到仓库。最终测试至少检查：

- 能识别 12 段非矩形边界和短回折，不能简化为矩形，也不能把门扇或尺寸线变成额外墙段。
- 能读出并正确绑定 `1590`、`1640`、`615`、`1840`、`2855`、门宽 `800`、门高 `2055`。
- 能区分 `2855` 与相邻的 `55`，避免重复累计短回折。
- 上方、左侧和门墙尺寸链能够闭合；样例中 `4105` 与 `4110` 的 `5 mm` 差值应自动吸收，不能判为识别失败；无法唯一确认的点位必须保持待确认。
- 改变草图中任一墙线的像素长度但保留相同尺寸标注时，生成的毫米边界不得变化。
